# 实施计划

本页按建议实施顺序记录后续工作；功能基线见 [实现状态](implementation-status.md)。计划中的接口在实现并验证后加入 [CLI 参考](cli-contract.md)。

## OKF 诊断与本地读取完善

- 增加来源脚注与 `sources[].id` 的关联检查，以及 `Attested Computation` 合同诊断；实现时扩充 [检查矩阵](okf-validation.md)。
- 解析概念间的 Markdown 链接，处理包根路径、文档相对路径和片段，提供断链诊断。
- 统一过大卡片的处理规则，完善配置锁恢复与缓存修复流程。

验收要求：缺失可选字段、未知类型与扩展字段保持可消费；规范错误与质量建议分开；链接解析限制在包内，并覆盖引用式链接与代码围栏。跨平台结果保持一致的 Concept ID、原文字节和 JSON 语义。

## Git 知识包

- 增加仓库地址、包根和 ref 绑定，将 ref 解析为 commit 后读取 tree/blob。
- 读取仓库对象时保持知识包只读，不执行 hooks，也不自动初始化 submodule 或 LFS。
- 明确刷新、对象缓存、凭据引用和授权隔离的规则。

验收要求：分支更新不改变已固定提交的分页结果；使用真实仓库测试更新、鉴权失败、离线缺失与传输中断，分别报告版本和可用性。

## 持久化索引与全文检索

- 提供显式同步、增量更新、事务发布的索引版本和离线正文缓存。
- 明确每个知识包的索引覆盖范围，支持重建与清理。
- 引入正文检索与结果片段，评估中文、代码符号和中英混合查询的匹配与排序。

验收要求：同步中断保留旧索引，并发刷新不混用版本；不完整枚举不误删条目；检索片段可追溯到内容版本和原文位置。先测量扫描与查询成本，再选择索引和分词方案。

## 任务上下文与 Agent 消费

- 按预算选择正文或章节，保留来源、版本和原文定位。
- 返回选择依据、覆盖缺口与继续读取入口。
- 评估多知识包结果融合与机器可读帮助。

验收要求：使用真实任务统计定位成功率、引用正确率、披露字节与调用次数；Agent 能识别过期、缺失和部分覆盖，不凭文本相似度推断业务关系。

## 对象存储与远端知识包

- 优先接入 S3 兼容存储，明确列举、条件读取和版本固定能力。
- 评估清单导航与分页列举，以及远端读取协议或专用适配器。
- 统一代理、超时、重试与下载预算；导入绑定时显式激活，限制重定向中的凭据转发。

清单与读取协议属于工具扩展，不增加普通 OKF 文件的格式要求。ETag 不直接等同内容哈希；无法保证跨文件一致性时使用观测视图。

验收要求：使用实际 S3 测试服务和 HTTP fixture 验证分页、更新、删除、权限拒绝、限流、超时和重定向；同一知识包经不同适配器读取后，模型与原文字节一致。

## 发布与性能

发布件包含版本信息、可执行文件、校验和与一致的消费 Skill。验收使用全新安装的二进制、真实知识包和各平台测试结果。

性能评估固定概念数量、文件大小分布、硬件与缓存冷热状态，同时记录读取字节、目录列举和文件读取次数，以基线数据决定缓存与索引优化。
