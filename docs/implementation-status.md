# 实现状态

本文记录功能范围与已知边界。可执行命令见 [CLI 参考](cli-contract.md)，模块职责见 [产品与架构](architecture.md)，未交付能力见 [实施计划](roadmap.md)。

## 功能范围

| 领域 | 范围 |
| --- | --- |
| 知识包 | 本地文件系统，项目与用户作用域绑定 |
| 加载 | 知识包概览、一层目录、概念卡片、原文字节分页 |
| 检索 | 有界元数据子串匹配；任务上下文返回候选和读取入口 |
| 合规 | frontmatter、概念类型、保留索引与日志日期检查 |
| 状态 | 元数据派生的审核、文档状态与过期声明 |
| 持久化 | TOML 绑定、SQLite 卡片观测记录 |
| Agent | 消费 Skill 安装与机器可读响应 |

## 已知边界

- 知识包采用观测视图，目录分页不保证固定快照。
- SQLite 不存正文，不提供离线读取，不作为完整索引；搜索每次访问知识包。
- 检索不读取正文匹配，不做相关性排序；`context --query` 不自动选取正文。
- Markdown 正文按原文传递，没有链接图、章节解析或断链检查。
- 扫描量、文件大小、目录规模和输出受限，没有 deadline 与取消机制。
- 共用分页参数按命令生效，详细范围见 CLI 参考；部分不适用参数仍会被解析但不参与执行。
- 单文件和目录故障的隔离范围不同，多知识包请求仍可能被文件或缓存错误终止。
- 配置使用独占锁文件，进程异常退出后需确认没有写入者，再清理遗留锁。
- text 输出为缩进 JSON；帮助输出是文本。

## 验证方法

从仓库根目录执行 [README 中的开发检查](../README.md#开发)。需要离线验证时，先完成依赖下载，再为 Cargo 构建、测试和 Clippy 命令添加 `--offline`。

CLI 场景使用临时项目与独立的 `OKF_HOME`，覆盖知识包作用域、目录与原文分页、Unicode 和空格路径、BOM/CRLF 重组、元数据搜索、缓存隔离、资源上限、异常退出码、Skill 防覆盖和并发配置写入。按 [响应 Schema](../schemas/response.schema.json) 校验 JSON，同时检查退出码、stderr 与源文件完整性。

符号链接、Windows Junction、循环目录和大小写碰撞应在适用平台验证。发布验收使用真实优化构建，检查运行时依赖，并在没有 Rust 与 C 编译器的环境中执行基本命令。跨平台结果由各平台测试和 CI 确认。
