## 功能范围

| 领域 | 范围 |
| --- | --- |

| 加载 | 知识包概览、一层目录、概念卡片、原文字节分页、索引上的直接入链与出链 |
| 检索 | 实时元数据匹配；同步索引上的正文子串匹配、元数据优先排序、章节内原文片段与任务上下文选择；目录范围、类型、标签、状态、审核层级和有效期筛选，可固定评估时间 |
| 合规 | 概念结构与保留文件检查；元数据、来源脚注、正文路径、包内链接目标、计算合同及声明资源检查；可选附件与标题锚点检查 |
| 状态 | 元数据派生的审核、文档状态与过期声明 |
| 持久化 | TOML 绑定、SQLite 卡片观测记录与独立正文索引；完整扫描事务发布、并发版本比较、离线原文分页、只读索引完整性检查 |
| Agent | 消费 Skill 安装与机器可读响应 |
| 执行控制 | 适配器内扫描预算、协作式截止时间和 Ctrl+C 取消 |
| 故障处理 | 多知识包隔离、文件诊断和缓存不可用时保留读取结果 |
| 质量门槛 | 可选警告数量上限；不完整统计返回未知总数和明确的门槛结论 |
| 发行准备 | 内嵌构建来源、按 Rust target 命名的校验包、tag 一致性检查、手动创建 Release 草稿 |

## 已知边界

- 文件系统采用观测视图，目录分页不保证固定快照；Git 读取固定 commit，索引分页绑定已发布 generation。列举不完整时需要提高扫描预算后重试。
- `index.sqlite` 保存历史卡片观测，`content.sqlite` 保存显式同步的正文。同步重新读取源文件并计算哈希，在事务内更新正文与版本；容量与扫描限制见 CLI 参考。
- 全文检索与上下文选择支持多包共享预算、确定性子串匹配和排序，保留各自的 generation。默认路径扫描；`--candidate-budget` 可启用有界字符三元组候选，仍由原文复核匹配。尚未引入分词或语义冲突判定。
- 链接目标检查限于 `validate` 完整列举后的包内 Markdown 文件与显式目录；普通正文附件和 `headings-v1` 锚点可显式启用检查；图片、自定义 HTML 锚点与外部资源不在确定性检查范围内。
- `Attested Computation` 检查字段形状、计算正文及包根相对声明资源的存在性与文件类型；外部 URI 不访问，计算执行与 Receipt 核验属于独立后续能力。
- 截止时间和取消在检查点生效，不能强制中断已阻塞的系统 I/O、数据库操作或序列化。
- 配置采用系统文件锁，进程异常退出会释放所有权，锁文件本身保留。
- Git 远端当前支持无交互的公开 HTTPS 获取，不提供私有仓库凭据配置、SSH、submodule 或 LFS 下载。Git 对象缓存支持占用查询、写入预算及保留历史对象的压缩；暂不删除历史版本，也不限制精确网络传输字节。
- 上下文返回确定性原文窗口，并不生成答案或保证语义相关；已提供确定性检索证据任务集，真实 Agent 答案质量评测仍需独立进行。

参数、分页、故障处理与覆盖状态见 [CLI 参考](cli-contract.md)；结构、元数据与正文规则及其规范依据见 [OKF 检查矩阵](okf-validation.md)。

## 验证方法

从仓库根目录执行 [README 中的开发检查](../README.md#开发)。需要离线验证时，先完成依赖下载，再为 Cargo 构建、测试和 Clippy 命令添加 `--offline`。

CLI 验证使用临时项目和独立的 `OKF_HOME`，覆盖作用域、原文重组、目录分页、Unicode 路径、元数据搜索、资源上限、Skill 防覆盖和并发配置写入。按 [响应 Schema](../schemas/response.schema.json) 校验 JSON，同时检查退出码、stderr 与源文件完整性。

故障场景覆盖非知识文件的扫描计数、列举不完整时拒绝 cursor、多包故障、缓存打开与写入失败、超时及读取中途取消。检查已完成结果、未知覆盖状态和完整校验错误的优先级；结合注入取消信号与实际控制台信号验证取消行为。

Git 测试覆盖固定提交读取、刷新与对象类型限制；索引测试覆盖事务发布、版本冲突和离线原文读取。固定上游语料与测量方法见 [性能基线](performance.md)。

元数据与正文样例、边界场景和跨工具核对方法见 [范围与验证](okf-validation.md#范围与验证)；同时核对各读取命令的诊断一致性及原文定位。

符号链接、Windows Junction、循环目录和大小写碰撞应在适用平台验证。发布验收使用优化构建，核对发行包与文件哈希，并在 PATH 不含编译工具的环境中执行解压后二进制。CI 与打包工作流在 Windows、Linux、macOS 上共用交付验收入口。
